Hugging Face token

Token yalnızca bu telefondaki tarayıcıda saklanır; başka hiçbir yere gönderilmez, sadece Hugging Face'e bağlanırken kullanılır.

Token nasıl alınır?5 adımda, yaklaşık 1 dakika
  1. huggingface.co'da hesabınıza giriş yapın.
  2. Sağ üstteki profil resminize dokunup Settings → Access Tokens bölümüne girin.
  3. Create new token düğmesine basın.
  4. Token type olarak Read seçin, bir ad verin (ör. "atolye") ve oluşturun.
  5. Çıkan hf_ ile başlayan kodu kopyalayıp yukarıya yapıştırın.
